INSTALL
-------
1. Copy JM_GOLD_Session_Signal_v1.mq5 → MQL5\Indicators\
2. MetaEditor → F7
3. Copy both .tpl → MQL5\Profiles\Templates\
4. GOLD# chart → Indicators List → DELETE old indicator
5. Right-click → Templates → JM_GOLD_Session_M5

ANO ANG NASA VIEW
-----------------

Yellow PH hours sa TAAS ng bawat hour candle (8AM … 1PM … 11PM)
BUY ▲ cyan    SELL ▼ magenta
