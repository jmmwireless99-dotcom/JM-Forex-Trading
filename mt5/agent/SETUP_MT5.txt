SETUP (Windows PC na may MT5)
-----------------------------
1) I-Extract All ang jm-mt5-bridge.zip (hal. Desktop\jm-mt5-bridge)

2) MT5 → File → Open Data Folder → MQL5\Experts\
   - Copy JM_Forex_Bridge.mq5 dito
   - MetaEditor → Compile (F7) hanggang 0 errors
   - I-drag ang JM_Forex_Bridge sa XAUUSD chart
   - Inputs: UseCommonFolder = true
   - Common tab: ✅ Allow Algo Trading
   - Toolbar: Algo Trading = GREEN / ON
   - Chart comment dapat: trade_ok=YES

3) Agent
   - Double-click RUN_AGENT_MT5.bat
   - Huwag isara ang window
   - Dapat may "push ok=True" at status=yes ticks=yes

4) Check online
   https://jmtechsolution.cloud/fx/api/mt/status
   - platforms.mt5.online = true
   - mt_login = 25817283
   - trade_ok = true (o walang trade_block)

KUNG trade_ok=NO
----------------
- I-click Algo Trading toolbar OFF → ON
- Alisin EA sa chart → i-attach ulit
- Tools → Options → Expert Advisors → Allow algorithmic trading
- Experts tab: basahin ang "block=..." reason
