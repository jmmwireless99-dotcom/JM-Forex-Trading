------------------------
1) Extract jm-mt4-btc-bridge.zip

2) MT4 → File → Open Data Folder → MQL4\Experts\

   - MetaEditor → Compile (F7) — 0 errors
   - Buksan BTCUSD (o BTCUSDm / Bitcoin) chart → TIMEFRAME M5
   - I-drag JM_Forex_Bridge sa chart
   - Inputs:
       InpSymbol = BTCUSD   (auto-resolve suffix)
       UseCommonFolder = true
   - Common: ✅ Allow live trading
