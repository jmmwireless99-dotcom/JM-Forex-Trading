# JM FX MT5 Bridge — Quick install

## Copy this file

```
mt5/Experts/JM_Forex_Bridge.mq5  →  <MT5 Data Folder>/MQL5/Experts/
```

## MT5: Open Data Folder

**File → Open Data Folder → MQL5 → Experts**

## After compile

1. Attach **JM_Forex_Bridge** to gold chart (XM: often `GOLD` or `XAUUSD`)
2. `UseCommonFolder = true`
3. **Algo Trading ON**

## Shared files folder (Windows)

```
C:\Users\<YOU>\AppData\Roaming\MetaQuotes\Terminal\Common\Files\
```
