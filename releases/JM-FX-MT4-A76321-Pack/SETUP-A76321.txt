STEP 2 — Install EA sa MT4 REAL terminal
----------------------------------------
1. Buksan ang XM MT4 REAL account (live terminal — hindi demo, hindi MT5)
2. MT4 → File → Open Data Folder → MQL4\Experts\
3. Kopyahin ang Experts\JM_Forex_Bridge.mq4

STEP 3 — Allow WebRequest
-------------------------
MT4 → Tools → Options → Expert Advisors:

  [x] Allow WebRequest for listed URL
  Add URL: https://jmtechsolution.cloud

--------------------------------

  InpBridgeToken     = gTXmD7O-194jS9gveB1I5c9qjmNdqdUv
