JM GOLD SESSION SIGNAL v1.32 — indicator only
=============================================

Hindi EA. Walang OrderSend.

SAAN ANG ENTRY
--------------
Sa TAAS ng candle: lime BUY / red SELL.
Scroll pabalik (kahit January) - nandun pa ang dots. Hindi nawawala
pag lumipas ang candle.

Yellow/orange o = may setup, V640 hour OFF.

PANEL: History from YYYY.MM.DD | dots=N
N = ilang BUY/SELL sa lahat ng loaded bars.

MAX BARS
--------
Para umabot January: MT5 Tools → Options → Charts
  Max bars in chart = Unlimited (o 100000+)
Tapos right-click chart → Refresh. Scroll left.

INSTALL
-------
1. mq5 → MQL5\Indicators\  F7
2. Delete OLD indicator
3. Templates → JM_GOLD_Session_M5
